kemaolife-agent —— Windows 托盘程序 安装说明
================================================

包内文件：

  kemaolife-agent.exe   Windows 托盘常驻程序（GUI 子系统，无控制台窗口）
  install.bat           一键安装（双击即可）
  install.ps1           安装脚本本体，由 install.bat 调用
  uninstall.bat         一键卸载
  uninstall.ps1         卸载脚本本体
  LICENSE               MIT 许可证
  INSTALL.txt           本文件


一、安装
--------

把整个压缩包解压到任意目录（不要只把 exe 拿出来双击后又在压缩包里运行），
然后双击 install.bat。

脚本会：

  1. 结束正在运行的旧实例（运行中的 exe 无法覆盖）；
  2. 复制程序到 %LOCALAPPDATA%\Programs\Kemaolife\；
  3. 创建开始菜单快捷方式「科贸生活」；
  4. 启动程序一次。

安装不需要管理员权限，全部写当前用户范围。

为什么建议用脚本而不是直接双击 exe：程序的开机自启项记录的是 exe 的绝对路径。
直接在下载目录（或临时解压目录）里跑，之后一挪走或清空下载目录，自启项就成了
指向不存在文件的死项，而设置窗口仍会显示「已开启」。装到固定目录可以避免这个坑。

如果只想绿色使用、不装到固定目录，也可以直接双击 kemaolife-agent.exe，
只是不要开启「开机登录时自启动」。


二、第一次运行
--------------

首次启动没有学号，会直接弹出设置窗口，填完后点「保存」。
之后程序只留在系统托盘，关闭设置窗口只是隐藏，不会退出进程。
结束进程请右键托盘图标选「退出」。

配置保存在 %LOCALAPPDATA%\Kemaolife\，学号与密码经 Windows DPAPI 加密，
只能由当前 Windows 用户解密，拷到别的机器也解不开。

开机自启：设置窗口里「开机登录时自启动」默认就是勾上的，但只有点「保存」才会
真正写入当前用户的注册表启动项。首次安装不保存就不会生效，也不会随安装脚本自动写入。


三、关于「未知发布者」提示
--------------------------

本版本没有代码签名证书，Windows 会因此给出两类提示：

1. SmartScreen：双击后可能显示「Windows 已保护你的电脑」。
   点「更多信息」→「仍要运行」即可。

2. Smart App Control（Windows 11 22H2 起，新装设备默认开启）：
   开启状态下会直接拦截未签名程序，且不提供「仍要运行」按钮。
   遇到时只能在「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制」
   里关闭它——关闭后无法再重新开启（除重装系统），请自行权衡。

如果你安装的是 arm64 版本，请参见第五节关于实机验证的说明。


四、卸载
--------

双击 uninstall.bat。脚本会结束进程、删除自启项、删除开始菜单快捷方式、
删除 %LOCALAPPDATA%\Programs\Kemaolife\。

配置目录 %LOCALAPPDATA%\Kemaolife\（含加密的学号与凭据）**不会被删除**，
重装后可以直接沿用。确认不再使用时可手动删除该目录。


五、架构说明
------------

  amd64   64 位 x86（主流 Intel / AMD 机器），已在实机验证
  arm64   64 位 ARM（Windows on ARM 设备）
arm64 版本可以正常构建，但**尚未在 ARM 真机上运行验证**。托盘图标、右键菜单、
设置窗口、凭据加解密这四处都依赖手写的 Win32 结构体布局，未经实机确认。
遇到问题请带 Windows 版本与具体现象提 Issue：
  https://github.com/EchoPing07/kemaolife/issues

不出 32 位 x86（386）版本：Windows 11 没有 32 位版，Windows 10 32 位也已停止支持。


六、更新
--------

1. 右键托盘图标 →「退出」；
2. 解压新版本压缩包，重新运行 install.bat；
3. 配置与凭据会沿用，不需要重填。
