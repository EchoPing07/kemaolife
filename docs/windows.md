# Windows 主窗口与托盘（kemaolife-desktop）

`kemaolife-desktop.exe` 是给人用的原生桌面程序：**主窗口 + 常驻托盘**。主窗口固定为「今天 / 课表 / 电费 / 校园网 / 设置」五页，同时保留电费轮询、阈值提醒与校园网手动 / 自动认证。Windows 既能主动提醒，也能直接查看完整信息。

## 1. 形态与生命周期

- 原生 Win32 UI（纯 Go `syscall` 直调，无第三方依赖、无浏览器内核），**GUI 子系统**，无控制台窗口。
- 普通双击启动时显示主窗口并定位到「今天」。关闭主窗口只隐藏到托盘，不退出进程；只有托盘菜单「退出」才结束进程。
- 单实例互斥。重复启动不创建第二个进程：不带 `--background` 时唤起已有主窗口（已有实例仅驻留托盘、主窗口尚未创建时，通知其创建并显示）；带 `--background` 时直接退出，不改变已有实例的窗口状态（互斥量创建失败时不阻断启动）。
- 开机登录时通过 `--background` 自启一次（见 §8）：新实例只驻留托盘，不显示主窗口。**不保活、不守护**：被用户退出或系统杀掉后不重启。
- 启动先读取本地课表快照并显示「今天 / 课表」，再后台独立同步课表；同时立即查一次电费并判一次校园网状态。各后台动作不阻塞 Win32 消息循环。
- 首次启动无学号时显示主窗口并定位到「设置」；普通启动与自启的上述区别仍由 `--background` 决定。

## 2. 安装与卸载

从 [Releases](https://github.com/EchoPing07/kemaolife/releases) 下载 `kemaolife-desktop_<版本>_windows_<架构>.zip`（`amd64` 或 `arm64`），**解压到任意目录后双击 `install.bat`**。脚本会结束旧实例、复制程序到 `%LOCALAPPDATA%\Programs\Kemaolife\`、建开始菜单快捷方式并以普通方式启动一次（显示主窗口），不需要管理员权限。也可直接双击 `kemaolife-desktop.exe` 绿色运行，只是此时建议不要开启开机自启（自启项记录的是 exe 绝对路径，程序一挪位置就失效）。

卸载双击 `uninstall.bat`：结束进程、删自启项、删快捷方式与安装目录，**保留** `%LOCALAPPDATA%\Kemaolife\` 配置目录（含 DPAPI 加密的学号、教务密码与校园网凭据，重装可沿用）。

> **本版没有代码签名**。Windows 会提示「Windows 已保护你的电脑」（点「更多信息 → 仍要运行」）；开启了 Smart App Control 的 Windows 11 设备会直接拦截且不提供放行按钮，只能到「Windows 安全中心」关闭 SAC（关闭后无法重新开启）。免费开源签名的跟进项见 [#4](https://github.com/EchoPing07/kemaolife/issues/4)。

> **`arm64` 版本尚未在 ARM 真机上验证**。构建可以通过，但主窗口、托盘图标、右键菜单与凭据加解密都依赖手写的 Win32 结构体布局，未经实机确认；遇到问题请带 Windows 版本与现象提 Issue。不出 32 位 `386`（Windows 11 没有 32 位版）。

安装 / 卸载脚本源码在 [`packaging/windows/`](../packaging/windows/)。`.ps1` 必须带 UTF-8 BOM + CRLF（PowerShell 5.1 读无 BOM 的 UTF-8 会按系统 ANSI 解码导致语法错误），`.bat` 必须 CRLF，由 `.gitattributes` 与 release 校验保证。脚本不写自启项：自启只由「设置」页「保存」写入，保证注册表路径与 `os.Executable()` 一致。

## 3. 主窗口五页

五页共享同一个主窗口；UI 只渲染 DTO 与本机状态，业务计算留在 Go 的 `core` / `app`。

### 3.1 今天

展示当天的 `DaySchedule`，包含日期、周次、星期、是否学期内与当天课节。读取使用 `GetSchedule(..., CacheOnly)`，只读本地快照、0 请求，不因打开页面或返回页面而联网。页面提供独立「刷新课表」，行为见 §3.2。

今天页同时提供电费与校园网摘要卡（余额 / 采集时刻、三态 / 检查时间，复用各自域的 DTO 与脱敏错误）和「刷新全部」：后者并行触发课表同步、`PollOnce` 与校园网判态，不串行等待。

### 3.2 课表

以完整周视图展示 `GetWeekSchedule(..., CacheOnly)` 返回的 7 天课表，可切换到任意周次。**切周、返回当周与页面切换都只读本地快照，不联网，也不触发隐式刷新**；`CacheOnly` 的 `stale` 恒为 `false`，快照同步时间单独展示。

联网只由独立 `SyncTimetable` 动作触发：

- 启动先加载已有快照，再后台同步一次；同步成功后用新快照重读当前页。
- 「刷新课表」手动触发同一用例，不与切周查询合并。
- 同步失败保留并继续展示旧快照，在页面显示脱敏错误；无快照时引导先同步，不用空课表冒充无课。
- 多次触发不得让旧请求覆盖新会话或新账号的数据。

### 3.3 电费

展示完整 `ElectricityReport`：余额、单位、可用天数等概况，以及 `yearMonth`、`monthUse`、`dataUntil` 和按日期升序的 `days[]` 完整表格。页内必须标注「数据截至 `<collectedAt>`」，`dataUntil` 以「用量统计至 `<dataUntil>`」单独标注；这不是托盘状态的展示口径。

提供「立即查询电费」按钮、月份输入 / 选择与「查询」：「立即查询电费」走 `PollOnce`，保留 §5 / §6 的轮询与告警语义；手动月份查询调用 `Engine.QueryElectricity(ctx, yearMonth)`，按指定月份重新获取完整报告。查询成功更新报告、检查时间并清除旧错误；失败只显示脱敏错误，保留旧报告，不返回半份数据。**历史月份手动查询不触发余额告警，也不改变轮询失败退避**。

### 3.4 校园网

展示三态：`online`（已在线）/ `unauth`（未认证）/ `offline`（不在校园网 / 探测失败），并显示最近一次本机动作或轮询形成的脱敏错误提示。页面动作与模式一致：手动模式提供登录 / 下线 / 重登 / 立即探测；自动模式提供重登 / 立即探测。动作直接调用既有 `app` 用例，不新增 DTO 或对外门面。

不展示接入详情：`brasName` / `brasAddress` / `vlan` / `deviceIp` / `mac` 不进入 Windows UI，隐私边界见 [privacy.md §4](privacy.md)。

### 3.5 设置

原生 Win32 控件，字段：学号、教务密码、学校代码（留空用内置默认）、校园网账号 / 密码 / 指纹参数、自动模式、开机自启、电费间隔、探测间隔、余额阈值、可用天数阈值、静默起止小时。

- 教务密码与校园网凭据是独立字段；教务密码用于课表同步，校园网密码不复用它。
- 打开设置页回显当前生效配置；两类密码字段恒为空（留空即不修改），不回显已保存凭据。
- 表单内容超出可视区域时纵向滚动；「保存」「还原」与提示行固定在页面底部，不随表单滚动。
- 非法数值拒绝保存；间隔低于下限钳制后保存并显示实际生效值。
- 密码输入留空表示保留已保存密码；配置显示不得泄露明文密码。
- 配置存 `desktop/config` 键，经用户级 DPAPI 加密后原子写入 `%LOCALAPPDATA%\Kemaolife\`；课表快照含 Cookie，同样按敏感数据加密存储。

## 4. 托盘

左键单击托盘图标唤起主窗口并定位到「今天」。右键菜单保留两行只读状态，每行单行简短：

- 校园网认证状态：`校园网：已在线` / `校园网：未认证` / `校园网：不在校园网`（不显示探测时刻、不带上游长文案）。
- 剩余电费：`剩余电费：<余额> <单位>` 或 `剩余电费：未获取`（不带可用天数）。

**托盘菜单与悬浮提示均不展示「数据截至」**；错误原因放在托盘悬浮提示里分行显示（按 Win32 128 个 UTF-16 码元上限截断）。下方按钮组按模式切换：

| 模式 | 按钮 |
|---|---|
| 手动（默认） | `登录校园网` / `下线` / `重登` |
| 自动 | `重登` |
| 两种模式通用 | `立即探测校园网` / `立即查询电费` / `设置…` / `打开主窗口` / `退出` |

「设置…」打开主窗口并定位到「设置」页（见 §3.5），不再使用独立设置对话框。网络动作均离开消息循环在后台执行。

## 5. 校园网轮询与电费轮询

### 5.1 校园网

状态三态可查（契约见 [contract.md §7.4](contract.md#74-校园网)）；**手动 / 自动二选一，默认手动**。探测的目的是判断「在不在校园网、认证状态如何」，**不是探测一般互联网连通性**。

- **手动模式**：主窗口与托盘按钮执行登录 / 下线 / 重登；电费轮询失败只更新状态，不自动登录。
- **自动模式**：未认证时自动登录、已在线不重复认证，作为每轮电费轮询的前置；前置认证失败只更新状态，不阻断本轮电费。仍保留「重登」按钮。
- **判态轮询**：常驻期间按固定间隔只发探测（不发登录、不改凭据），与电费轮询是两个独立周期。**默认 120 秒**，设置页可自定义，低于 30 秒钳制到 30 秒并提示；启动时先判态一次。探测失败归 `offline`，不退避。
- **立即探测校园网**：两种模式都提供，立即探一次判态并刷新主窗口与托盘状态，不登录、不改任何凭据。
- 「重登」= 先判态，已在线则下线并复探（约 2~3s 生效等待），未认证跳过下线，随后登录并复探确认。
- 凭据独立字段，不复用教务密码；DPAPI 加密，每轮现读，设置保存后立即生效。
- 探测按 `api-docs/003` 的固定地址判 302；自签证书跳过校验仅限 Portal HTTPS 客户端（探测地址是 HTTP 明文）。

### 5.2 电费

启动立即查一次，之后轮询余额 + 每日用量（估算可用天数）。**默认 4 小时（14400s）**，设置页可自定义，**低于 600s 钳制到 600s 并提示**（硬下限，不可放行）。托盘菜单与电费页的默认「立即查询电费」均可触发 `PollOnce`；月份查询走 §3.3 的独立手动路径。

一次查询 = 2 个主请求（`getbindroom` + `getusedetail`）+ 1 个采集时刻请求（失败静默降级），任一主请求失败整体报错。连续失败按指数退避（§6 规则 6），失败不弹余额通知。

## 6. 告警规则

告警判定是 `core/alert.Evaluate` 纯函数（旧状态 + 当前电费 + 注入时钟 + 配置 → 决策 + 新状态），由 `internal/desktop.Engine` 在 `PollOnce` 电费成功路径调用。通知渠道为系统通知为主、托盘状态为辅：当前由托盘 `NIF_INFO` 承载，进程 AUMID `Kemaolife.Desktop` 仅用于归类，样式随 Windows 版本变化（气泡 / toast），不承诺 WinRT Toast 或操作中心归档。

1. **阈值**：`balance <= threshold` 或 `estimatedDays <= daysThreshold` 触发提醒。
2. **去重**：余额阈值与可用天数阈值各用独立标记；同一触发原因只提醒一次，余额回升到阈值以上（充值）后重置余额标记，可用天数高于阈值后重置天数标记。
3. **静默时段**：静默时段内不发送通知、也不置位告警标记（本轮余额与用量仍照常计算），退出静默后若仍满足条件则补发一次。
4. **数据时间**：通知正文必须包含「数据截至 `<collectedAt>`」。
5. **失败不告警**：电费查询失败不触发余额提醒，只更新状态；自动模式前置认证失败同样只记到状态，但不阻断本轮电费查询与余额提醒（两者是独立链路）；手动校园网动作失败也不弹失败通知。历史月份 `QueryElectricity` 不调用告警判定。
6. **退避**：电费成功路径按轮询间隔执行；连续失败时按指数退避重试，间隔从轮询间隔起步且逐步增大（不得比成功路径更频繁），不重复弹出失败通知；上限取 24 小时的保守值。校园网判态轮询失败归 `offline`，不退避；月份手动查询不修改电费轮询的连续失败计数。

默认值：

| 项 | 默认 | 说明 |
|---|---|---|
| 电费轮询间隔 | 4 小时（14400s） | 可自定义，≥ 600s 硬下限，低于则钳制 |
| 校园网判态间隔 | 120 秒 | 可自定义，≥ 30s 下限，低于则钳制 |
| 余额阈值 | 10 度 | 可配置 |
| 可用天数阈值 | 3 天 | 可配置 |
| 静默时段 | 23:00–07:00 | 可配置 |
| 失败退避 | 起点 = 轮询间隔，指数增长 | 上限 24 小时 |

## 7. 设置保存与生效

「设置」页保存后立即更新内存配置；各轮询下一轮重读设置，校园网动作与课表同步使用当次配置。教务密码、校园网凭据与快照均不得写日志或错误信息。保存失败保留当前编辑内容并显示脱敏错误，不以默认值覆盖有效配置。

## 8. 开机自启与启动参数

开机登录时自启一次，设置页可开关（默认勾选）；**仅在设置保存时**写 HKCU `Run` 项（值名 `KemaolifeDesktop`），首次安装不写、不自动生效。不写守护进程、不注册服务、不保活。

注册表命令为 `"<kemaolife-desktop.exe 的绝对路径>" --background`。`--background` 只控制新实例的初始窗口状态：驻留托盘、不显示主窗口，后台轮询与启动同步照常执行；普通双击不带此参数，显示主窗口。该参数不是退出、隐藏已有窗口或第二实例模式；已有实例时，带此参数的重复启动直接退出，不带此参数的重复启动按 §1 唤起主窗口。安装脚本仍以普通方式启动，无需单独处理该参数。

## 9. 构建

正式构建必须按 GUI 子系统（详见 [release.md](release.md)）：

```bash
GOOS=windows GOARCH=amd64 go build -trimpath \
  -ldflags "-s -w -H=windowsgui" \
  -o kemaolife-desktop.exe ./cmd/kemaolife-desktop
```

不带 `-H=windowsgui` 会多挂一个控制台窗口（程序启动时会自己 `FreeConsole` 摘掉，但仍不符合 GUI 子系统形态）。`arm64` 把 `GOARCH` 换成 `arm64` 即可。

## 10. 不做的事

多账号、云端同步、浏览器内核、保活与后台守护、WinRT Toast / COM 激活器 / 快捷方式通知。课表快照同步只保存本人数据到本机，不属于云端同步。
