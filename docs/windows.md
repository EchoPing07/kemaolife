# Windows 托盘（kemaolife-desktop）

`kemaolife-desktop.exe` 是给人用的原生托盘常驻程序：**电费轮询 + 阈值提醒 + 校园网手动 / 自动认证**。Windows 主动说——这是它相对 Android 的结构性优势。不做课表主界面。

## 1. 形态与生命周期

- 原生 Win32 UI（纯 Go `syscall` 直调，无第三方依赖、无浏览器内核），**GUI 子系统**，无控制台窗口。
- 关掉任何窗口都不退出，只有托盘菜单「退出」才结束进程；关闭设置窗口只是隐藏。
- 单实例互斥，重复启动只提示已在运行（互斥量创建失败时不阻断启动）。
- 开机登录时自启一次（见 §8），**不保活、不守护**：被用户退出或系统杀掉后不重启。
- 首次启动无学号时直接打开设置窗口；启动后立即查一次电费并判一次校园网状态。

## 2. 安装与卸载

从 [Releases](https://github.com/EchoPing07/kemaolife/releases) 下载 `kemaolife-desktop_<版本>_windows_<架构>.zip`（`amd64` 或 `arm64`），**解压到任意目录后双击 `install.bat`**。脚本会结束旧实例、复制程序到 `%LOCALAPPDATA%\Programs\Kemaolife\`、建开始菜单快捷方式并启动一次，不需要管理员权限。也可直接双击 `kemaolife-desktop.exe` 绿色运行，只是此时建议不要开启开机自启（自启项记录的是 exe 绝对路径，程序一挪位置就失效）。

卸载双击 `uninstall.bat`：结束进程、删自启项、删快捷方式与安装目录，**保留** `%LOCALAPPDATA%\Kemaolife\` 配置目录（含 DPAPI 加密的学号与凭据，重装可沿用）。

> **本版没有代码签名**。Windows 会提示「Windows 已保护你的电脑」（点「更多信息 → 仍要运行」）；开启了 Smart App Control 的 Windows 11 设备会直接拦截且不提供放行按钮，只能到「Windows 安全中心」关闭 SAC（关闭后无法重新开启）。免费开源签名的跟进项见 [#4](https://github.com/EchoPing07/kemaolife/issues/4)。

> **`arm64` 版本尚未在 ARM 真机上验证**。构建可以通过，但托盘图标、右键菜单、设置窗口与凭据加解密都依赖手写的 Win32 结构体布局，未经实机确认；遇到问题请带 Windows 版本与现象提 Issue。不出 32 位 `386`（Windows 11 没有 32 位版）。

安装 / 卸载脚本源码在 [`packaging/windows/`](../packaging/windows/)。`.ps1` 必须带 UTF-8 BOM + CRLF（PowerShell 5.1 读无 BOM 的 UTF-8 会按系统 ANSI 解码导致语法错误），`.bat` 必须 CRLF，由 `.gitattributes` 与 release 校验保证。脚本不写自启项：自启只由设置窗口「保存」写入，保证注册表路径与 `os.Executable()` 一致。

## 3. 托盘右键

两行只读状态，每行单行简短：

- 校园网认证状态：`校园网：已在线` / `校园网：未认证` / `校园网：不在校园网`（不显示探测时刻、不带上游长文案）。
- 剩余电费：`剩余电费：<余额> <单位>` 或 `剩余电费：未获取`（不带可用天数）。

**托盘菜单与悬浮提示均不展示「数据截至」**；错误原因放在托盘悬浮提示里分行显示（按 Win32 128 个 UTF-16 码元上限截断）。下方按钮组按模式切换：

| 模式 | 按钮 |
|---|---|
| 手动（默认） | `登录校园网` / `下线` / `重登` |
| 自动 | `重登` |
| 两种模式通用 | `立即探测校园网` / `立即查询电费` / `设置…` / `退出` |

网络动作均离开消息循环在后台执行。左键单击托盘图标打开设置窗口。

## 4. 校园网

状态三态可查（`online` / `unauth` / `offline`，契约见 [contract.md §7.4](contract.md#74-校园网)）；**手动 / 自动二选一，默认手动**。探测的目的是判断「在不在校园网、认证状态如何」，**不是探测一般互联网连通性**。

- **手动模式**：托盘按钮执行登录 / 下线 / 重登；电费轮询失败只更新托盘状态，不自动登录。
- **自动模式**：未认证时自动登录、已在线不重复认证，作为每轮电费轮询的前置；前置认证失败只更新托盘状态，不阻断本轮电费。仍保留「重登」按钮。
- **判态轮询**：常驻期间按固定间隔只发探测（不发登录、不改凭据），与电费轮询是两个独立周期。**默认 120 秒**，设置窗口可自定义，低于 30 秒钳制到 30 秒并提示；启动时先判态一次。探测失败归 `offline`，不退避。
- **立即探测校园网**：两种模式都提供，立即探一次判态并刷新托盘状态行，不登录、不改任何凭据。
- 「重登」= 先判态，已在线则下线并复探（约 2~3s 生效等待），未认证跳过下线，随后登录并复探确认。
- 凭据独立字段，不复用教务密码；DPAPI 加密，每轮现读，设置保存后立即生效。
- 探测按 `api-docs/003` 的固定地址判 302；自签证书跳过校验仅限 Portal HTTPS 客户端（探测地址是 HTTP 明文）。

## 5. 电费轮询

启动立即查一次，之后轮询余额 + 每日用量（估算可用天数）。**默认 4 小时（14400s）**，设置窗口可自定义，**低于 600s 钳制到 600s 并提示**（硬下限，不可放行）。菜单可「立即查询电费」。

一次查询 = 2 个主请求（`getbindroom` + `getusedetail`）+ 1 个采集时刻请求（失败静默降级），任一主请求失败整体报错。连续失败按指数退避（§6 规则 6），失败不弹余额通知。

## 6. 告警规则

告警判定是 `core/alert.Evaluate` 纯函数（旧状态 + 当前电费 + 注入时钟 + 配置 → 决策 + 新状态），由 `internal/desktop.Engine` 在电费成功路径调用。通知渠道为系统通知为主、托盘状态为辅：当前由托盘 `NIF_INFO` 承载，进程 AUMID `Kemaolife.Desktop` 仅用于归类，样式随 Windows 版本变化（气泡 / toast），不承诺 WinRT Toast 或操作中心归档。

1. **阈值**：`balance <= threshold` 或 `estimatedDays <= daysThreshold` 触发提醒。
2. **去重**：余额阈值与可用天数阈值各用独立标记；同一触发原因只提醒一次，余额回升到阈值以上（充值）后重置余额标记，可用天数高于阈值后重置天数标记。
3. **静默时段**：静默时段内不发送通知、也不置位告警标记（本轮余额与用量仍照常计算），退出静默后若仍满足条件则补发一次。
4. **数据时间**：通知正文必须包含「数据截至 `<collectedAt>`」。
5. **失败不告警**：电费查询失败不触发余额提醒，只更新托盘状态；自动模式前置认证失败同样只记到托盘状态，但不阻断本轮电费查询与余额提醒（两者是独立链路）；手动校园网动作失败也不弹失败通知。
6. **退避**：电费成功路径按轮询间隔执行；连续失败时按指数退避重试，间隔从轮询间隔起步且逐步增大（不得比成功路径更频繁），不重复弹出失败通知；上限取 24 小时的保守值。校园网判态轮询失败归 `offline`，不退避。

默认值：

| 项 | 默认 | 说明 |
|---|---|---|
| 电费轮询间隔 | 4 小时（14400s） | 可自定义，≥ 600s 硬下限，低于则钳制 |
| 校园网判态间隔 | 120 秒 | 可自定义，≥ 30s 下限，低于则钳制 |
| 余额阈值 | 10 度 | 可配置 |
| 可用天数阈值 | 3 天 | 可配置 |
| 静默时段 | 23:00–07:00 | 可配置 |
| 失败退避 | 起点 = 轮询间隔，指数增长 | 上限 24 小时 |

## 7. 设置窗口

原生 Win32 控件，字段：学号、学校代码（留空用内置默认）、校园网账号 / 密码 / 指纹参数、自动模式、开机自启、电费间隔、探测间隔、余额阈值、可用天数阈值、静默起止小时。

- 非法数值拒绝保存；间隔低于下限钳制后保存并显示实际生效值。
- 关闭窗口只隐藏，不退出进程。
- 配置存 `desktop/config` 键，经 DPAPI 加密后原子写入 `%LOCALAPPDATA%\Kemaolife\`。

## 8. 开机自启

开机登录时自启一次，设置窗口可开关（默认勾选）；**仅在设置保存时**写 HKCU `Run` 项（值名 `KemaolifeDesktop`），首次安装不写、不自动生效。不写守护进程、不注册服务、不保活。

## 9. 构建

正式构建必须按 GUI 子系统（详见 [release.md](release.md)）：

```bash
GOOS=windows GOARCH=amd64 go build -trimpath \
  -ldflags "-s -w -H=windowsgui" \
  -o kemaolife-desktop.exe ./cmd/kemaolife-desktop
```

不带 `-H=windowsgui` 会多挂一个控制台窗口（程序启动时会自己 `FreeConsole` 摘掉，但仍不符合 GUI 子系统形态）。`arm64` 把 `GOARCH` 换成 `arm64` 即可。
