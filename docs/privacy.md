# 隐私与合规

本文是项目隐私规则的**唯一来源**。AGENTS.md、CONTRIBUTING.md、SECURITY.md 与各端文档只引用本文，不重复全文。

## 1. 只查本人数据

电费接口**无鉴权**（IDOR），身份凭证只有学号。因此：

- 只允许查询账号本人数据；不实现多账号、批量遍历、代查他人。
- 不把电费 / 教务 / Portal 接口包装成对外服务（HTTP API、公开脚本、SaaS）。
- 不做电费充值、绑房间、解绑房间。

这是法律边界，不是功能取舍。

## 2. 个人隐私禁止入仓

真实学号、姓名、密码、Cookie、会话值、`roomverify`、`distoken`、指纹值、课表快照内容，以及**用户本机**内网 IP / MAC / 宿舍房间号，禁止出现在仓库任何文件：代码、注释、测试夹具、文档、提交信息、Issue、PR。

示例一律用占位符：`<学号>`、`<密码>`、`<roomverify>`、`<校区>_<楼栋>_<楼层>_<房间>`。

**学校事实允许入仓**：学校代码 `customercode`（内置默认 `3126`）、学校公开的 Portal / 探测 IP、BRAS 名称属学校与协议事实，不算个人隐私。学校代码可作 `cmd` 层内置默认值并支持覆盖，但不得写成 `internal/core` 包级常量或对外发布的通用常量。

## 3. 凭据与快照存储

凭据只能存进平台加密存储，禁止明文落盘、写进配置示例或 README：

| 平台 | 方式 |
|---|---|
| CLI（linux / darwin） | 目录 `0700` / 文件 `0600`，原子写，XDG 路径优先 |
| Windows 托盘 | 用户级 DPAPI 加密 |
| Android | Keystore 加密，凭据解密后只存在于 Go 进程内存 |

课表快照含会话 Cookie，**等同凭据**：同样加密或 `0600` 存储，禁止把快照内容粘贴进对话、Issue 或文档。校园网凭据是独立字段，不复用教务密码。

## 4. 日志与错误输出

- 日志只允许记录错误类别、耗时、状态码。
- 上游错误文案（`message_` / `exception_` / `body.message` 等）必须先脱敏再输出，不得原样透传。
- 本人查询结果的 `roomName` 允许在本机 CLI 输出（DTO 字段），但不进日志、错误信息或 agent 复述；`roomVerify` 恒脱敏。
- 校园网探测下发的六参数只在内存构造表单，不落仓库 / 日志 / 错误信息 / 对外分享；`brasName` / `brasAddress` / `vlan` / `deviceIp` / `mac` 仅在本人设备 Android「更多」页折叠展示；`distoken` 不进 DTO 或 UI。

## 5. 数据时效标注

电表数据约有 **1 天延迟**，不是实时值。CLI 人类可读输出、Windows 告警通知正文、Android 电费页必须标注「数据截至 `<collectedAt>`」；Windows 托盘菜单与悬浮提示只显示当前值，不展示采集时刻。

## 6. Android 本机缓存最小化

- Kotlin 侧课表展示镜像与电费缓存只写 UI 必需字段，不含 Cookie / 凭据 / 学号 / `roomName` / `roomVerify`。
- `allowBackup=false`，Android 12+ 的 `dataExtractionRules` 排除全部私有数据。
- 凭据身份变更时清两类缓存，并让 Go 删除旧快照。

## 7. 请求日志（Android 设置页「日志」）

请求记录是排查能力，不是对外契约：

- 默认关闭，只有用户显式打开才记录；关闭立刻清空。
- 只存 Go 进程内存，不落盘、不进 logcat，进程结束即消失。
- 标头与正文按原始字节保留（含 Cookie 与表单字段），不做字段级遮罩——排查协议需要看清真实报文。因此**记录内容一律不得进入仓库、文档、测试夹具或 Issue**；本人设备上的日志由用户自行决定不外发。
- 单段正文超过 64 KiB 时截断并标注（内存保护，非脱敏）。

## 8. 误提交处置

发现敏感信息被误提交时，不要公开引用原文，按 [SECURITY.md](../SECURITY.md) 走私有渠道报告。
