# Android App

Kotlin + Compose 原生 App，给人「随手看」：胶囊悬浮底栏三个 tab（**课表 / 更多 / 设置**），进入设置二级页时底栏自动收起，支持系统与二级页预测性返回。打开即用，不申请自启动、不做后台定时。业务计算全部在 Go 核心（经 gomobile 门面），UI 只消费 DTO；门面契约见 [contract.md §6](contract.md#6-android-门面)，本地构建见 [android/README.md](../android/README.md)。

## 1. 安装

从 [Releases](https://github.com/EchoPing07/kemaolife/releases) 下载**一个**对应架构的 APK：多数近几年手机用 `arm64-v8a`，旧 32 位机用 `armeabi-v7a`，`x86` / `x86_64` 主要给模拟器用。系统需 Android 7.0（API 24）及以上。直接在手机上打开 APK 安装，首次侧载需要在系统提示里允许该来源的「安装未知应用」；也可 `adb install -r <APK>`。

四个包共用同一把发布私钥与同一 `applicationId`，**新版直接覆盖安装即可**，设置页 Keystore 里的凭据与应用私有目录里的课表快照都会保留；不要先卸载再装。发布签名证书的 SHA-256 指纹写在每版 Release 说明里，可用 `apksigner verify --print-certs <文件>` 核对；指纹不一致时不要安装、不要填任何凭据。

只发侧载 APK，不上架应用商店，不自动检查更新；可在「设置 → 关于 → 检查更新」手动对比版本号（§8），再回 Releases 页下载同架构 APK 覆盖安装。签名与发布流程见 [release.md](release.md)。

## 2. 缓存优先与触发策略

这是 Android 端最重要的行为规则：

**每次打开 App（含从后台回到前台）**

1. 首帧由 ViewModel 同步读 Kotlin 侧课表展示镜像与电费缓存立即渲染，**不等待门面 `Init`**（0 请求）。镜像带快照版本，版本不匹配时清空回到中性空态。
2. 门面 `Init` 就绪、凭据已填且无同链路在途请求时，发起一次 `timetable.sync`、一次电费查询与一次必要的校园网判态。打开是**特殊自动触发，不受最小查询间隔约束**。
3. 任一成功立刻覆盖对应界面，并把当周视图回写展示镜像；课表失败沿用旧缓存、置 UI 离线标记并保留 `syncedAt`，不弹错误、不阻塞展示；电费失败沿用其缓存，不弹错误 snackbar（失败原因可在设置页「日志」与电费详情页「测试」弹窗查看）。

**启动时序**：门面 `Init` 是 JNI 调用，可能晚于 `ON_RESUME`。`Init` 完成前不得触发自动查询；补发的初始 `ON_RESUME` 不算打开，真正的打开在 `Init` 前到来时挂起一次、成功后补跑，冷启动恰好一轮；`Init` 失败保留挂起，设置页保存成功后补跑。内部未就绪错误不进课表位 / snackbar，只由设置页展示。

**其余触发**

| 触发 | 行为 |
|---|---|
| 切周 / 周次弹窗 / 横向翻页 | 只读缓存（`timetable.week`，`CacheOnly`，0 请求），不联网 |
| 切回课表 tab、进入「更多」页 | 自动触发，按各自「最小查询间隔」节流；间隔内只显示缓存 |
| 手动「刷新」、设置页「测试」 | 永远不受间隔约束 |

**最小查询间隔**：课表与电费各自独立，均默认 **5 分钟**、下限 **1 分钟**、上限 **1440 分钟**（1 天），越界值钳制到合法边界并提示。各记「上次尝试时刻」（单调时钟），失败也记账，断网时切 tab 不会连打接口。Windows 托盘的 600 秒硬下限只属于 Windows 轮询，不适用于 Android。

**离线语义**：查询类 `op` 是 `CacheOnly`，信封 `stale` 恒 `false`；UI 的离线标记只由独立 `timetable.sync` 的结果维护，任何纯读缓存不得覆写它。`sync + 回读` 作为事务提交，回读失败保留旧数据与旧数据时间并置离线。飞行模式下打开即出整学期课表。

## 3. tab1 课表

单页周视图：每页一周，星期日期行与 12 小节 × 7 天网格同页放进**横向翻页容器**（相邻周并排、跟手拖动、松手吸附），左滑下一周、右滑上一周，竖向滚动位置跨周保持。

- 头部固定显示**当天日期**，同时显示正在浏览的周次与今天所属的当前周次；浏览周即今天所在周时并排显示今天周几。点击日期 / 周次区域弹出周次列表，支持选周与「返回当前周」。
- 右上角 `导出课表` / `刷新` 两个按钮，同步 / 离线时间（`同步于 …` / `离线 · …`）排在按钮下方。
- 翻页边界依据 `timetable.week` 的可选 `lastWeek` 生成周次序列（UI 不自己算周）；相邻周由 ViewModel 预取进内存缓存，预取失败静默。冷启动镜像不带 `lastWeek` 时按有限窗口生成临时页码，`Init` 后回读补齐，不据此拦截翻页。
- 课程块按 `periods` 跨行、撞课分栏、按课程名固定配色；默认在网格块与「更多」页今日概览展示精简后的课室名、在非空课室前加 `@` 并允许课名 / 课室 / 教师完整换行展示（可在「设置 → 教务 → 高级」调整「课室显示优化」「课室前显示@」「过长隐藏」，前两项默认开启、「过长隐藏」默认关闭），点课程块查看完整条目与原始地点。今天那一列只用字重强调，不加背景。
- **导出课表**：调 `timetable.export`（只读快照、0 请求）把整学期课节导出为 WakeUp 课程表 CSV（格式见 [contract.md §7.2](contract.md#72-课表导出wakeup-课程表-csv)）；默认导出原始课室名，可在「设置 → 教务 → 高级」开启「导出优化课室」（默认关闭）。弹层先展示文件名、课节数与快照同步时间，确认后经系统文件选择器（SAF）落盘，不申请存储权限；文件名由 Go 侧给出。
- `timetable.date` 门面能力保留，但主页不提供按天选择入口。

## 4. tab2 更多

三张卡片 + 取件码卡片：

- **今日概览**：当天课表，右上角 `刷新` 走与课表页相同的 `timetable.sync` + 回读。
- **电费情况**：余额、数据截至、用量（可用天数 / 本月已用并排呈现），右上角 `刷新`。进入本页时按最小查询间隔自动查一次。
- **校园网情况**：三态 + 探测时刻 + `offline` 说明，右上角 `刷新`（判态）+ 手动 `登录` / `下线` / `重登`；`brasName` / `brasAddress` / `vlan` / `deviceIp` / `mac` 五项非空接入详情默认折叠展示。状态未知或非 WiFi 跳过标记仍在时不按间隔、直接判态一次。卡片不渲染上游历史提示（`errorMsg`）；手动动作失败原因走 snackbar。
- 三张卡片的 `刷新` 均为手动动作，不受间隔约束。**「测试」只在设置页对应详情页提供**。
- **取件码**：`淘宝` / `拼多多` 两个并排按钮，点击经深链跳转对应 App 的取件码页：私有 scheme 候选按序尝试并锁定目标包名，再试钉包名的官方 H5，最后交系统浏览器，全部失败才本机提示。纯呈现层跳转，不发请求、不读凭据 / 本机数据（协议事实见 [api-docs/004](../api-docs/004-pickup-deeplink/README.md)）。菜鸟与待取快递入口不做。

## 5. tab3 设置

多级页面：总览 → 各详情页，进入二级页时自动隐藏悬浮底栏，支持预测性返回手势（跟手预览设置总览并同步恢复底栏）与左上角返回。

| 分组 | 条目 |
|---|---|
| 账号与服务 | **教务**（学号 + 密码 + 高级：最小查询间隔、课室显示优化、课室前显示@、过长隐藏、导出优化课室）/ **电费**（「继承教务信息」开关默认打开，关闭后单独填电费学号；学校代码在此设置；最小查询间隔）/ **校园网**（独立账号 + 密码 + 选填指纹，不复用教务密码；「仅在 WiFi 下探测」开关默认打开） |
| 个性化 | **颜色模式**（系统 / 浅色 / 深色三选一，连体钮形态，切换即生效）/ **外观**（莫奈动态取色、AMOLED深色模式、连续曲率圆角、底栏文字标签开关、预设主题色）/ **预测性返回手势**（默认开启；关闭后侧滑返回二级页不跟手预览，松手走常规退场） |
| 关于与支持 | **关于** / **日志** / **交流** / **分享** |

- 三个功能域详情页右上角均有 `测试` 按钮（`*.probe`），弹窗展示耗时、错误码与脱敏摘要；保存按钮为右下角纯图标悬浮按钮（自动避让系统导航栏与软键盘），教务 / 电费的查询间隔随本页保存生效。
- Keystore 加密凭据，密码不回显；保存后重新 `Init` 门面，凭据身份变更时清课表镜像、电费缓存与 Go 快照。
- **外观**：Android 12+ 莫奈动态取色默认开启，不支持的设备沿用预设主题；预设取 AOSP ThemePicker 的 8 个基础色；AMOLED 开关可随时设置，纯黑背景只在深色界面生效；「连续曲率圆角」默认关闭（标准圆弧），开启后全 App 改用连续曲率圆角，半径层级不变；「底栏文字标签」默认开启（悬浮底栏同时显示图标与文字），关闭后切为更紧凑的纯图标形态；偏好本机持久化，升级不做旧偏好迁移。
- **日志**：请求记录开关默认关闭，下方列出已记录的请求，点条目看完整详情，可清空。记录只存 Go 进程内存、按原始字节保留报文，隐私边界见 [privacy.md §7](privacy.md)。
- **交流**：点击走 QQ 官方「一键加群」发起加群申请（`mqqopensdkapi://bizAgent/qm/qr?url=<percent-encoded 内层 url>`，内层为官方生成的 `http://qm.qq.com/cgi-bin/qm/qr?...&k=<key>`，原样保留官方参数）；QQ 未安装或无接收者时回落 README 同一加群短链，均失败才本机提示。群号与 key 都是公开分发信息，链接不拼任何本机数据；key 按群生成，换群必须改常量并发版。
- **分享**：经系统分享面板发送固定三行纯文本（`KeMao Life · 科贸生活` / `官网：https://echoping07.github.io/kemaolife/` / `项目地址：https://github.com/EchoPing07/kemaolife`），不含任何查询结果 / 凭据 / 日志 / 接入详情，不联网。
- **关于**：版本 / 设备与 Android / 官网 / GitHub / MIT 许可 / 检查更新（§8），官网、GitHub 与开源许可同组外链。

交流、分享、取件码、检查更新都是 Kotlin 呈现层能力：不读门面、不新增 `op`、不携带本机私有数据。

## 6. 校园网 WiFi 门控

校园网全手动、不后台、仅校园网 WiFi 可用。「仅在 WiFi 下探测」默认打开：非 WiFi 时**所有** `campusnet.*` 调用（判态 / 测试 / 登录 / 下线 / 重登）都不发请求，直接落 `offline` 并说明「需连接校园网 WiFi」，不误报为认证失败；打开开关时立即把残留的 `online` / `unauth` 状态置为 `offline` 并禁用动作按钮。设置页可关闭该限制。蜂窝数据下判 `offline` 属正常态。

## 7. 本机数据与隐私

- 快照落应用私有目录长期复用（含 Cookie，等同凭据）；凭据加密与持久化留在 Kotlin，Go 只处理内存中的凭据。
- 课表展示镜像与电费缓存只写 UI 必需字段，不含 Cookie / 凭据 / 学号 / `roomName` / `roomVerify`；`allowBackup=false` 且 Android 12+ 备份 / 迁移排除全部私有数据。
- 明文 HTTP 探测仅对探测地址放行（`network_security_config.xml`），不全局 `usesCleartextTraffic`；Portal 自签证书由 Go 侧专用 HTTPS 客户端处理，不全局 `InsecureSkipVerify`。
- 完整规则见 [privacy.md](privacy.md)。

## 8. 检查更新（纯手动）

关于页「检查更新」打开半屏底部弹层，自动发一次检查：只取 GitHub `GET /repos/EchoPing07/kemaolife/releases/latest` 的 `tag_name`，与 `BuildConfig.VERSION_NAME` 按 `v?X.Y.Z` 白名单做三段数值比较，展示「当前版本 / 最新版本 / 一句结论」；失败用本地固定文案，关掉弹层重新点击即重查。底部「前往 Releases」按钮跳 Releases 列表页。

不自动检查、不后台定时、不应用内下载或安装 APK；请求走 JDK `HttpURLConnection`（标准库），不带凭据 / Cookie / 学号 / 设备标识，不经 Go 门面（故不进请求日志）。打开 App / 进入关于页 / 后台均不触发。
